# Results Directory

This directory is reserved for generated analysis outputs. The notebooks create the required subdirectories automatically when they are run.

Expected generated layout:

```text
results/
  01_single_cell_prediction/
  02_time_series_analysis/
  03_spatial_analysis/
```

These output files are not tracked in Git by default. To reproduce them, run the notebooks in `analyses/` after restoring the processed data files under `data/`.

The time-course R scripts read `results/02_time_series_analysis/Bortezomib_score.csv`, which is generated by `analyses/time_series_analysis.ipynb`.
